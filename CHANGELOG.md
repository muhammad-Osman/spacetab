# Changelog

All notable changes to SpaceTab. The format follows [Keep a Changelog](https://keepachangelog.com/).

## 0.9.0 — 2026-10-09

First public pre-release, unsigned: open it with right-click → Open the first time. It doesn't update itself yet.

### Added
- ⌥ Tab switches between the windows on the current desktop, in most recently used order, with a quick tap flipping between the last two.
- Three styles: Titles, App Icons and Thumbnails (live previews).
- Search: press `/` while the switcher is open and type; Return switches.
- Actions on the selected window: W close, M minimize, Q quit app, F full screen, H hide app.
- Up to 9 shortcuts, each for the windows on the current desktop, on all desktops, or of the current app. ⌃⌥ Tab lists windows on all desktops by default.
- Minimized windows and windows of hidden apps, shown, shown at the end, or left out.
- Windows from all screens or only the screen with the mouse; windows grouped by app.
- Apps that never appear in the switcher.
- Mouse and trackpad: move over a window to select it, click to switch.
- Light, dark and system themes; size, spacing, corner radius, background and animation settings; the system's Reduce Transparency and Reduce Motion settings are respected.
- Shortcuts keep working while an app has secure input on, for example in a password field.
- Menu bar icon that can be hidden, launch at login, settings import and export.
- Automatic updates through Sparkle.
- Languages: English, German, French, Spanish, Portuguese, Japanese, Simplified and Traditional Chinese.
